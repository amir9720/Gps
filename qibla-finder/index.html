How Digital Web Compasses Work

Modern smartphones are equipped with a magnetometer—a tiny micro-electromechanical sensor (MEMS) that detects the Earth's magnetic field. This tool accesses that sensor via the HTML5 DeviceOrientation API to rotate the compass dial, keeping "North" correctly aligned no matter how you turn your phone.

Calculating the Qibla Direction

The Qibla is the fixed direction towards the Kaaba in the Grand Mosque in Mecca, Saudi Arabia (Latitude: 21.4225, Longitude: 39.8262). Once you grant GPS permission, this tool calculates the shortest path (the great-circle track) from your exact coordinates to Mecca using spherical trigonometry, and places a green marker precisely on the compass dial.

Handling Magnetic Interference

Electronic appliances, steel girders in modern buildings, and magnetic phone cases can severely distort magnetometer readings. For the most accurate bearing, use this tool outdoors or near a window, away from computers and heavy machinery.

Frequently Asked Questions

Why does the web browser ask for motion and orientation permissions on iOS?

Apple (iOS 13 and later) requires explicit user interaction to read gyroscope and magnetometer data to protect your privacy. Clicking the "Enable Compass" button securely requests this access directly inside Safari without downloading an app.

Does this tool use True North or Magnetic North?

The tool attempts to use True North by factoring in the magnetic declination if the hardware and operating system provide it (such as `webkitCompassHeading` on iOS). On standard Android devices, it defaults to magnetic north, which is usually accurate enough for everyday use.
